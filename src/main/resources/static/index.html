Delivery pipeline

Every commit flows through the same automated stages in Jenkins. A failing test stops the pipeline before anything is deployed.

1 CommitGit feature branch, pull request, merge
2 BuildMaven compiles and runs unit tests
3 PackageWAR archived as a build artefact
4 ImageDocker image on Tomcat, versioned 1.0.N
5 VerifySelenium runs five user journeys
6 ReleasePush to registry, deploy container
7 OperateAnsible provisions, checks health, rolls back
